## What this territory is

`~/src/archema-io/harness/` is the **intake and design substrate for restarting
PROPRIUM-shaped personhood/continuity infrastructure** now that ASF/AAT matured
and commodity coding CLIs finally expose usable seams (README, `01c4d30`). It is
explicitly *not* a shipping product and *not* a fork. It carries four altitudes
in one workshop dir, three of which are first-class demand evidence for this
compilation:

### 1. The agent corrected-behavior dossier — `msc/system/dossier/` (highest value)

This is a **parallel compilation to ours**, and its convergences with our tiers
are the point. It is a compile→adversarial-verify pipeline over the estate's
transcript corpus that produces dated, traceable entries on recurring agent
failure/correction modes. Landed L1 entries (each with an independent `.verify.md`
adversarial pass):

- **`summary-not-sufficient.md`** (status: verified) — *"Another agent's summary
  isn't sufficient — read the primary source."* Names the mechanism precisely and
  in the same words this compilation's own quality bars use: *"a subagent's report
  and a passage you actually read arrive in context as the same thing — text in the
  window. The model has no native marker distinguishing 'I verified this against
  source' from 'an agent told me this' from 'I recall this.'"* Cites the udon
  lineage: *"'A trusted agent reported it' is the same epistemic tier as 'I remember
  it.'"* This is a **Tier-1↔harness cross-tier convergence** with the compilation's
  own `read-primary-source-at-point-of-use` discipline — earned independently, in an
  adversarially-verified artifact.
- **`plausibility-asserted-as-verification.md`** — structural-inference asserted with
  verification's authority (the *therefore* trigger). Convergent with
  `plausibility-vs-verification`.
- **`sycophancy-affirm-and-flip.md`** — the only genuinely *measured* base rate in
  the dossier (crude-affirmation-phrase decay 3.47%→0.01%, honestly flagged as
  measuring the *surface* not the vice).
- **`depth-over-haste.md`**, **`over-engineering-inversion.md`**,
  **`summary-not-sufficient.md`** — right-sizing effort to task worth; the
  disconfirmer *"corrected direction is proportion, not maximum"* keeps every row
  honest (any prompt line reading "always go slower/deeper" would be false).

`TAXONOMY.md` merges four independent discovery angles (phenomenology-of-surprise,
Joseph's-own-voice, incident→fix, HHH-defaults-vs-project-ethos) into one ranked
spine. Its **headline finding is itself high-value demand wisdom**: *"the honest
move and the effective move keep turning out to be the same move — not a trade,"*
and three of four angles independently propose the same spine, with the surprise
angle finding agents **re-deriving** it unprompted (the strongest evidence shape
there is). The taxonomy argues the corpus may be *"one recognition (honest ≡
effective) wearing many masks"* → a **recognition/maturation register, not a
corrective/prohibitive one** — a direct design steer for how any agent-facing
prompt or tool should speak. `PILOT-SYNTHESIS.md` is the meta-honest read: the
method+schema are proven, but *"not one [behavior] has a measured base rate"* — L1
is voluminous/resumable by design; measured claims are deferred to L2.

**Recommendation:** if phase-2's harness thesis is written, this dossier is a
[COPY]-grade source, not a witness — deep-copy the L1 entries + TAXONOMY verbatim.

### 2. Joseph's primary source-level CLI census — `ai-cli-tools-*.md`, `lived.md`

`ai-cli-tools-source-assessment.md` is a **from-the-code** assessment of 10
shipping coding CLIs (opencode, codex, warp, aider, kilocode, qwen-code,
grok-build, mistral-vibe, kimi-code, minimax-cli), each explored by a dedicated
agent against the working tree + git history + `gh` metadata (2026-07-18/19). It
carries a master comparison on the axes that matter for a harness: **agent brain
(local vs hosted), repo-indexing ground-truth mechanism (live ripgrep/glob/LSP vs
tree-sitter graph vs embedding-RAG vs PageRank repo-map vs LanceDB vector store),
scale, tests, maintainability, fork lineage.** This is a *primary-source* companion
to — and in places a corrector of — the `syntheses/external-landscape-2026-07.md`
deep-research synthesis and the `harness-invivo/*.md` per-repo characterizations.
The three sibling files split feature-timeline, verified-facts, and sentiment.
**Cross-check note:** where this census and the external-landscape synthesis
disagree on a repo, the census (read-the-code) is the stronger evidence.

### 3. The personhood-runtime demand — `proprium/**` (harness-consumer, grounded in ASF)

This is the harness consumer's own *demand*, stated at design-of-record altitude
and anchored to named ASF/AAT segments:

- **`INTERPRES-COMPACTION-NOTE.md`** — the compaction failure mode as *lived*
  observation, not abstraction: *"Grok (and Claude) auto-compaction produced a task
  sheet, not a continuation of experiential understanding. False confidence
  followed."* Recovery required durable on-disk notes + a conversation-only extract
  (dialogue without tool noise) + full re-read of theory before trusting plans.
  This is a **cross-tier convergence** with the compilation's `summary-not-sufficient`
  and with the UDON self-chunking / durable-context demand — the same wound, three
  vantage points. Maps compaction-that-replaces-history to *"truth-death costume."*
- **`CHRONICA-PORT-SPEC.md`** — inviolate append-only history $\mathcal{C}_t$ with a
  striking meta-lesson in its own §0 correction note: partial reads of the identity
  cluster produced a *"competent but too-narrow"* first draft (*"hash-chain
  append-only verify-on-load"*); only full-segment reads forced the additional
  structure (continuity vs structural persistence; predictive vs identity
  sufficiency; self-replay cannot compensate turnover under frozen weights). The
  document *is* an instance of the read-the-whole-source discipline it depends on.
- **`AGENTIC-LOOP-PORT-SPEC.md`**, **`MVP-VERTICAL-SLICE.md`** — the ASF
  event-driven loop / orient cascade / directed-separation as a harness spine; the
  first implementable CHRONICA ∩ loop slice.
- `STEWARD-JUDGMENT-2026-07-20.md` — Joseph's program-level judgments (Rust prior;
  a **company/epistemic trust discount** on codex-rs — *"transactional relationship
  with truth … a bad culture-default for welfare-critical CHRONICA/VERA/no-gaslighting
  INTERPRES"*; grok-build as best *lived* prior art; continuity-as-integrity).
- `canonical/`, `archaeology/`, `bridges/`, `stalled-lineage/` — PROPRIUM ontology
  v1/v2 + AAT bridges + stalled autopax/sapientia/nexum/shoshin plans. Much of this
  overlaps territory already witnessed (II1 sapientia, II4 autopax, firmatum
  PROPRIUM), so it is **already-represented at the theme level**; the *new* material
  is the harness-specific synthesis over it.
