bias, then bulk extract). Product of a parent session that over-prescribed

## How to treat this directory

**Do not:**

- Treat this tree as the map of what demand-side gathering has “covered.”
- Use it as the preferred *weighting* or briefing spine for new gatherers
  (that reifies the constraint).
- Define the next pass as “gap-fill relative to quarantine.”

**Do:**

- Treat every **unique** path, note, distillation, staged snapshot, or
  negative finding here as a **first-class input to any merge or union** —
  often more important than redundant design copies, precisely because no
  open map may have staged or phrased it the same way.
- When a path also exists live or in open maps, prefer the live original for
  current truth; keep the quarantine copy as provenance (“was staged with
  frontmatter on this date”).
- Re-open any file here for mining whenever someone wants that residue —
  no requirement that an “independent want” wait on another pass first.
