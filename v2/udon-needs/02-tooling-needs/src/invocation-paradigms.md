# PLANNED — Invocation paradigms: one-call-per-tool, code mode, grammar-constrained freeform

per-call JSON tools; "code mode" (tools as callable API inside a sandboxed
interpreter; 3-way convergence incl. official Anthropic
programmatic-tool-calling); grammar-constrained freeform (codex lark
patches). Each moves the reliability burden to a different layer; deferred
loading (C7) reshapes catalog design for all three.

position against BFCL error-profile finding; consequences for tool-catalog
