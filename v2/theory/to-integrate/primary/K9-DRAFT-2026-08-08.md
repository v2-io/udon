## The ruling (draft text)

**K9 — Sameline is value-space.** All sameline prose is an attribute value; the
only question is which attribute. Specifically:

1. **`$main`.** An element's sameline text is sugar for the designated
   attribute `:'$main'` (same sugar family as `$key`/`$traits`/`$?` — MODEL
   §3.1). Sugar-produced `$main` assignments are born finished (K8 applies).
   A `$main`-only element has not begun content: block attributes below it are
   ordinary and silent — the interleave pain case dissolves with no tier
   machinery.
2. **The sameline slot is a typed value position.** Self-announcing values
   (`"…"`, `<…>`, `[…]`, numbers, `!{{…}}`) become `$main` values and return
   the scan; unquoted prose commits flow to EOL (ordinary §6.4). Sequences are
   **stacked `$main` assignments** (canonical substrate; array is the view —
   SEMANTICS stacking≠list untouched). Accepted price, stated as guidance:
   *sameline text is a scalar — start a text body next-line-indented,
   especially if it opens with `"` or `<`.* Escapes: `\` at the slot forces
   flow; quote the whole thing.
3. **R4 narrows** (Overturns row): at a **clean value-expected position** — no
   flow committed — a brace form self-delimits as a value and the scan
   continues; whitespace is a separator. Mid-flow, R4 stands (the ruled
   `:n value |{em x} :a 1` example is unchanged). Where the clean position
   exists (per the fork's cell-by-cell): sameline `$main` slot, attribute
   value slots, **list items** — and NOT identity brackets (K2 stands) and NOT
   the K7 first-deferred-line (no continuing scan to return to). Inline-element
   *interiors* keep space-as-content (bracket mode; stated, not discovered).
   Precedent making this a generalization rather than an exception:
   interpolation `!{{x}}` already self-delimits as a whole value (and resolves
   the standing §6.3-vs-§9 contradiction about it).
4. **Consequences, named** (follow from 1–3; not separately decidable):
   - Sameline material is never *content*: `|el |{a} |{b}` = two stacked
     `$main` values; `content` is empty. Children-walkers and paths queries
     read `$main` for sameline material; AST builders MAY re-inject it as a
     first child behind a host flag (`first_is_main`-style).
   - `|el :a 1 extra` → `a=1`, `$main="extra"`. Sameline ≢ vertical **for
     text**, by design; reflowing a tail is a semantic edit (SEMANTICS
     forbidden-changes gains the row; formatters lose that freedom).
   - Node-vs-flow value distinction collapses at the clean slot
     (`:x |em hi` ≡ `:x |{em hi}` in the model) — Overturns row; §6.8's
     "drop braces to bind" sentence is rewritten.
   - S11 (inline verbatim = flow segment in value position) follows R4's fate
     at the clean slot — same Overturns row.
   - MODEL §4 gains `InlineElement` as a Value kind (bookkeeping).
   - The K-series warned-accept tier for late attributes is NOT needed;
     genuinely-late attributes (after real block content) keep §6.9's existing
     warned-text treatment unless/until demand says otherwise.
5. **Parked, explicitly not in K9:** `\` mid-sameline semantics (ESC-BREAKOUT,
   OPEN) — candidate restatement from the fork: "`\` forces text mode at the
   cursor" (keeps `:a \` ≡ `""` intact). The vim-modes/virtual-line mental
   model goes to RATIONALE, not law.

## ⟨CHOICE 1⟩ — text-extraction participation (one sentence in MODEL §6)

As written, attribute values are not part of text reconstruction; the tail used
to participate as a Text child and must not silently drop out.

**Recommended sentence:** *Each `$main` assignment participates in text
reconstruction as one virtual line: its lexical text followed by `"\n"`, in
source order; other attributes do not participate.* — Falls directly out of the
virtual-line model; the dialogue idiom `|element "hello," she said` then
reconstructs as `hello,\nshe said\n` (two virtual lines — the typed string's
content included via its lexical text).

Alternatives if the recommendation reads wrong: (a) only *flow* `$main`s
participate (typed scalars are data → `she said\n` alone); (b) `$main`
participates with no added join (pure concat → `hello,she said`).

## ⟨CHOICE 2⟩ — the designated name

`$main` (capture-doc default) vs bare `$` (spike's ten-second alternative:
`:'$'` — shortest, reads as "the value of the element itself"). Paths will
type this name forever; one deliberate minute.
