# Critical-to-quality factors for lite: a first draft for Joseph's weights

*Drafted 2026-10-22 by the agent of session `017CGtyM`, at Joseph's request, to score branches of the type-and-notation exploration (`types-ideation-2026-10-22.md`). It merges his 2011 table (`~/src/_older/udon/doc/objectives.asciidoc`, Concern-level 0–10) with lite's four objectives (`obj/`), reread for agents as the principal readers and writers. Every weight in "Proposed" is the agent's draft; the 2011 column is his. Nothing here is ratified.*

**How a branch is scored.** A **veto** factor is pass/fail: a branch that fails one stops there (as the streaming law stopped whole-run typing). The rest are weighted 0–10 and traded against each other. A branch's **impact radius** (below) is a cost, not a quality of the language.

## Evaluating a branch, beyond the factors

- **Impact radius**: the cards a branch changes, adds or deletes, weighted by each card's `strength` (forced > decided > lean > provisional), plus whatever it reopens. A cost, set against the factor scores.
- **Pruning**: a branch stops when it fails a veto, or when it can no longer render the composite example set honestly ("getting so messy").
