## Conventions

- **Notation:** mermaid `railroad-peg-beta`. `<-` defines, `/` is ordered choice, `*` `+` `?` quantify, `( )` group, `"…"` is a terminal, `&e` and `!e` are lookahead (match without consuming), `.` is any character. `%%` is a comment and renders as nothing.
- **Captures:** an **UPPERCASE** rule is lexical and disposable; a **lowercase** rule is captured, and its name is the AST field or node kind it produces. A lowercase rule whose body is only a lexical token captures that token's characters (so `trait <- "." LABEL` captures the label's characters as the trait). Nothing else is annotated, which is why it renders.
- **The lexer, not the PEG, owns the columns.** It turns a line's leading spaces into a column, emits `EOB` when a line sits at or left of an open block's column (once per block closed; the root is at column −1), emits `EOFB` at a fence closer of at least the opener's length, and knows which mode it is in (value mode on a block's start line and under an attribute; prose mode under an element's line, with the left edge; raw inside a fence). Those are listed at the end. Python's reference grammar is the precedent: a PEG that mentions `INDENT`, `DEDENT` and `NEWLINE` as if they were characters.
- **Joseph's lookahead, 2026-10-21:** a start character not followed by `{` begins a block; followed by `{` it is an embed. `!{` is a reserved embed ("potato potato"), caught at the same place.

## The grammar

```mermaid
railroad-peg-beta
title "UDON lite, block grammar over the lexer's tokens (tentative 2026-10-21)"
document <- blocks EOF ;
blocks <- block* ;
block <- BLANK / comment / element / attribute / fence / reserved / prose ;
%% ordered choice: prose is whatever is left. Which line a block begins on, and when it ends (EOB), is the lexer's; a block may begin mid-line (Joseph's pseudo-line-feeds) and then owns the later lines deeper than its own column
start <- ("|" / ":" / ";" / "@" / "!" / FENCE) !"{" ;
%% a start character not followed by { begins a block (Joseph, 2026-10-21); with { it is an embed. The same starts end a text in value mode
element <- "|" !"{" head (main block)* main framed-comment? EOB ;
%% the first main is on the element's own line (value mode): its values are the implicit attribute $main and stack. Each block may begin on that line or on a later line. After the line's end an element holds blocks only (prose mode), so later mains are empty. A value written after a block begun on the same line belongs to that block unless a framed backslash ended it (BS-SEP)
head <- name? key* trait* ;
name <- LABEL / quoted-name ;
%% OPEN: LABEL's characters (the labels discussion); quoted-name follows the delimited-string rules
key <- "[" value "]" ;
%% OPEN: one key or several (rule:keys-and-traits gap). Escapes inside: \\ \[ \]
trait <- WS* "." LABEL ;
%% OPEN, provisional: spaces before a trait (rule:traits-may-follow-spaces); while that stands a bare LABEL can't begin with "."
main <- (WS value)* ;
attribute <- ":" !"{" name (WS element / (WS value framed-comment?)+) (BS-SEP / EOB) ;
%% an element only as the first value (rule:element-after-attribute-with-no-value); otherwise values, which stack. BS-SEP is an inline end of the attribute's values: in |a :href / \ Home the Home is a's $main. OPEN: values on the lines below the attribute (rule:attribute-bodies gap) are values too, by Joseph's 2026-08-08 "attributes are assumed to be a typed scalar until proven otherwise". OPEN: |el :c 1 z gives z to c here (stacking), where rule:leftover-values gives it to $main; the two disagree
comment <- ";" !"{" RAW EOB ;
%% a comment block: the rest of its line and every deeper line, unparsed (rule:comment-blocks, rule:comment-block-owns-deeper-lines). No space is required after the semicolon; the lookahead keeps ;{ out. So ;|bunch-of-stuff comments out the block
framed-comment <- WS ";" !"{" (WS RAW / &EOL) EOB ;
%% after an item on a line (rule:framed-comments): a space on each side. Attaches to the nearest attribute, element or fence (Joseph, 2026-10-20); deeper lines are its, with a warning (rule:framed-comment-owns-deeper-lines). OPEN: whether end of line counts as the right-hand frame
fence <- FENCE !"{" head main (WS attribute)* framed-comment? EOL RAW* EOFB ;
%% the opener's line reads like an element's line (rule:fence-opener-line); an attribute opened there ends at the line's end, since the body is raw. What the default handler accepts (keys, the trait exact, a comment) is post-lexical (rule:fence-default-handler). The body is never scanned; each line keeps its ending; dedented by the handler unless exact (rule:fence-body-dedent, rule:fence-exact-trait). OPEN: TILDE fences (Joseph leans accept both)
reserved <- ("@" / "!") !"{" ;
%% error: a reserved start, wherever it is a block or a value (rule:reserved-spellings, rule:prose-line-start-reserved)
prose <- prose-line+ EOB ;
%% prose mode (rule:prose-passes-through): generous; a start mid-line is text. The first line sets the left edge; a deeper line is text whatever it begins with (rule:deeper-marker-lines-are-text); a start at the edge is a sibling block; shallower is EOB. Consecutive lines form one text (rule:text-lines-join); a comment block between them is a sibling, so the prose on either side is two texts
prose-line <- "\" ? (embed / escaped-embed / CHAR)* EOL ;
%% a leading backslash is consumed and sets the indent (rule:line-start-escape); a line holding only a backslash is a kept empty line (rule:lone-backslash-line)
escaped-embed <- "\" ("|{" / "@{" / ";{" / "!{") ;
%% the opener becomes literal text, the backslash consumed (rule:prose-escaped-embeds)
value <- string / number / "true" / "false" / "nil" / list / angle / element / text / reserved ;
%% kind by spelling, never by sniffing. OPEN: bare hello with no embed is a string of form bare (Joseph's 2026-10-20 sketch) or a one-piece text (the cards)
string <- double-quoted / single-quoted ;
double-quoted <- "\"" (dq-escape / dq-char)* "\"" ;
dq-char <- !("\"" / "\" / EOL) . ;
dq-escape <- "\" ( ("\" / "\"" / "'" / "/" / "#" / "n" / "t" / "r" / "f" / "e") / "0" !DIGIT / "x" "[0-7]" HEX / "u{" hex-run (WS hex-run)* "}" / "u" HEX HEX HEX HEX ) ;
%% rule:double-quote-escapes; any other backslash is an error
hex-run <- HEX (HEX / "_")* ;
single-quoted <- "'" (sq-escape / sq-char)* "'" ;
sq-escape <- "\" ("'" / "\") ;
sq-char <- !("'" / EOL) . ;
%% rule:single-quote-escapes; every other backslash is literal. A raw line ending in either string is an error (rule:newline-in-string-is-error)
number <- "???" ;
%% OPEN: the frozen bare set and its spellings (rule:bare-typing gap); Joseph leans toward what the old parser had
list <- "[" WS* (value (WS value)*)? WS* "]" ;
%% rule:list-items-whitespace-separated. OPEN: an unquoted item's extent, nesting, embeds as items
angle <- "<" RAW ">" ;
%% rule:opaque-span-raw-text: matched brackets nest; escapes only \\ \< \> (rule:opaque-span-escapes); must close on its line. OPEN, reopened 2026-10-20: an interior that is exactly nil, true, false, a number or a string would be a value of that kind
text <- piece+ &text-end ;
%% limited prose (Joseph, 2026-10-21): an unquoted value that ends at a start or a framed backslash. Its parts are bare strings and embeds; "piece" is his word for the slot, kept until he says otherwise
piece <- embed / bare-string ;
bare-string <- (escape / !(embed / text-end) .)+ ;
escape <- "\" "[set]" ;
%% OPEN: the set of attached escapes in value mode (rule:value-line-escapes); any other backslash would be an error
text-end <- BS-SEP / WS &start / EOL ;
%% the spaces before are frame, not content (rule:space-before-text-end); the framed backslash is consumed (rule:framed-backslash-frame); embeds never end a text (rule:embeds-in-text)
embed <- inline-element / reference / inline-comment / reserved-embed ;
inline-element <- "|{" INTERIOR "}" ;
%% OPEN: the interior is undesigned (Joseph, 2026-10-09); inside it an unquoted value also ends at "}" (rule:inline-element-value-end)
reference <- "@{" RAW "}" ;
inline-comment <- ";{" RAW "}" ;
%% both: matched braces nest; escapes only \\ \{ \}; must close on the line
reserved-embed <- "!{" ;
%% error: !{…} and !{{…}} are reserved everywhere, prose included
```

## What the lexer owns (not PEG)

| Token | What it is |
|---|---|
| `WS` | one or more spaces between items on a line; never a line's leading spaces. U+00A0 counts as a space with a default-off warning; a TAB or other whitespace that could shift a column is an error ([[rule:column-shifting-whitespace-error]]) |
| `EOL` | a line ending |
| `BLANK` | a line holding only whitespace; it never changes a column ([[rule:blank-line-sets-no-indent]]). Inside a text, whitespace on it past the left edge is content |
| `EOB` | end of block: the next line sits at or left of an open block's column. One per block closed. A block begun mid-line has the column of its start character; the root is at −1 ([[rule:top-level-columns]]) |
| `EOFB` | end of fenced block: a line whose first non-space content is at least as many backticks as the opener, with nothing after them but spaces or a framed comment ([[rule:fence-closes-at-n-or-more]], [[rule:fence-closer-trailing-text-is-error]]); its column then takes part in nesting like any line ([[rule:fence-closer-is-a-line]]) |
| `EOF` | end of input; any delimited form still open is an error ([[rule:unclosed-delimiter-is-error]]) |
| `FENCE` | three or more backticks, with no later backtick on the line ([[rule:fence-label-no-backtick]]) |
| `BS-SEP` | the framed backslash: `WS "\" WS`, consumed |
| `RAW` | characters carried without scanning; for a comment block, to the end of its deeper lines; inside `<…>` `@{…}` `;{…}`, to the matching closer on the same line |
| `CHAR` | any character in prose that is not an embed opener or line ending |
| `LABEL` | OPEN: the characters of a bare name (the labels discussion); `INTERIOR`, `DIGIT`, `HEX` likewise lexical |

Modes the lexer tracks: **value mode** on a block's start line and on the lines under an attribute (a start after `WS` ends a text); **prose mode** under an element's line (only line starts and embed openers are looked at; the first line sets the left edge); **raw** inside a fence until `EOFB`. Lines deeper than a prose block's left edge are handed over as prose lines even when they begin with a start character.

## What writing it exposed (for the cards, not decided here)

- `|el :c 1 z`: here `z` stacks on `c` (values after a block begun on the line belong to it); `rule:leftover-values` gives it to `$main`. The framed backslash is what returns a value to the element: `|el :c 1 \ z`. One of the two has to move.
- `$main` is not a rule in this grammar, only the name of the implicit attribute `main` captures; `rule:main-is-attribute` becomes a consequence.
- The lookahead answers the `;{` line-start question (an inline comment in prose) and removes the need for a space after a comment block's semicolon, which `rule:comment-blocks` already has.
- Four productions still have no body: `LABEL`, `number`, `INTERIOR`, and values on the lines under an attribute. Those are the gap rows plus the labels and embeds discussions.
