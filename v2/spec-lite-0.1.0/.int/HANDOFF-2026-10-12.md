### Decided since 2026-10-09 (most recent first)

- **Fences are specialized element nodes** (2026-10-12):
  - after the backticks, the opening line reads like an element's line: name (the "fence language", a label), keys, traits, attributes, `$main`, comment ([[rule:fence-opener-line]]);
  - after a finished value a fence is a **child**, by the element rules; Joseph first said `$main`, then withdrew it when shown that `|x` there is a child ([[rule:fence-anywhere-structure]]);
  - per-language handlers decide what a fence accepts; the **default handler** accepts only keys, the trait `exact` and a comment, errors on anything else "post lexical", and does the dedenting ([[rule:fence-default-handler]]);
  - `.exact` **replaces the `-` verbatim flag** ([[rule:fence-exact-trait]]).
- **Spaced traits, provisional** (2026-10-12): `|el .x` ≡ `|el.x`, so an unquoted name can't start with `.`; `|.asdf` is a nameless element with trait `asdf` ([[rule:traits-may-follow-spaces]]). A history search for any other reasoning is **on hold** at Joseph's word.
- **Labels** (2026-10-12, his table, in [[def:label]]): element names, traits, attribute names (`$key`/`$traits`/`$main` included) and the fence language are labels; a key is a value; `u64` is opaque. **Quoted labels hold anything except newlines.**
- **Fence opener ends sameline text**, in the family of `|`, `:`, `;` and the reserved spellings (2026-10-09; it deliberately reverses his July example) ([[rule:text-value-end]]).
- **Vocabulary rulings** (2026-10-09): «element» not node; «node» is generic; «attribute» not label; «label» = the lexical rules for names; one spelling, "sameline".
- Earlier the same days: `nil` only (bare `null` is an error); top-level attribute lines belong to the root; root at column −1; top-level prose edge 0 (lean); framed comment owns deeper lines past its `;` with a warning (lean); `"x""y"` is two values plus a warning (lean); inline-element value end; prose passes through. Each is a card; the outline lists them.
