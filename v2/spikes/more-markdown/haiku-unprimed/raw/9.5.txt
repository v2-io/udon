# Sample Report

This report includes a Python cell that runs when the document is rendered, so its output appears in the built document.

```{python}
#| label: summary
import platform
import statistics
import sys

values = [12, 7, 3, 25, 18, 9, 14]

print(f"Python version: {sys.version.split()[0]}")
print(f"Platform: {platform.system()}")
print(f"Values: {values}")
print(f"Mean: {statistics.mean(values):.2f}")
print(f"Median: {statistics.median(values)}")
print(f"Std dev: {statistics.stdev(values):.2f}")
```

The cell above computes basic statistics for the sample values and prints the Python version and platform.

To build this document, save it as `report.qmd` and run:

```bash
quarto render report.qmd
```

This produces `report.html` with the code output embedded. Quarto requires Python and the standard library only for this example.
