**How the identifier works**

- `{#install}` after the heading sets an explicit anchor ID, so the link target stays `#install` even if you later rename the heading (for example, to "Getting Started").
- Other places in the same document can link with `[Installation](#install)`, as shown in the Usage section.
- From other files, link with `guide.md#install` (or the published URL plus `#install`).

**Note on compatibility:** the `{#id}` syntax is supported by Pandoc, Python-Markdown (with `attr_list`), kramdown/Jekyll, MkDocs, Hugo, and many others, but not by plain CommonMark or GitHub-flavored Markdown. If you need it to work on GitHub, use an HTML anchor instead:

```markdown
<a id="install"></a>
## Installation
```
