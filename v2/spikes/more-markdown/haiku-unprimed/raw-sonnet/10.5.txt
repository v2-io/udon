Here's an HTML table with the second column three times as wide as the first (25% / 75%):

```html
<table style="width: 100%; table-layout: fixed; border-collapse: collapse;">
  <colgroup>
    <col style="width: 25%;">
    <col style="width: 75%;">
  </colgroup>
  <thead>
    <tr>
      <th style="border: 1px solid #000;">Column 1</th>
      <th style="border: 1px solid #000;">Column 2</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td style="border: 1px solid #000;">Narrow</td>
      <td style="border: 1px solid #000;">Three times as wide as the first column</td>
    </tr>
    <tr>
      <td style="border: 1px solid #000;">A</td>
      <td style="border: 1px solid #000;">B</td>
    </tr>
  </tbody>
</table>
```

`table-layout: fixed` makes the browser respect the `<col>` widths exactly, regardless of cell content.

If you need Markdown instead, standard Markdown doesn't support column widths, but you can pad the source so it looks proportional (rendered width depends on the renderer):

```markdown
| Col 1    | Column 2 (three times as wide as the first)         |
|----------|-----------------------------------------------------|
| Narrow   | Wide content goes here                              |
| A        | B                                                   |
```

Let me know if you need a different format (LaTeX, Word, CSS grid, etc.).
