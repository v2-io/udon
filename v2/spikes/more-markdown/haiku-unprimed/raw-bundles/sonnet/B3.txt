## 4. Code example

```python
def fibonacci(n):
    """Return the first n Fibonacci numbers."""
    seq = [0, 1]
    while len(seq) < n:
        seq.append(seq[-1] + seq[-2])
    return seq[:n]
```

## Notes

- **Index (item 6):** Quarto has no built-in index. The `\index{}` entry works for PDF/LaTeX output. In HTML it is ignored, so the sentence still reads normally.
- **To-do admonition (item 5):** Quarto has no dedicated to-do callout, so I used a `tip` callout titled "To-do".
- **Table footer (item 8):** Pandoc grid tables treat the second `===` line as the start of the footer.
- **Code cell (item 1):** It needs Python plus Jupyter available (`pip install jupyter`).
