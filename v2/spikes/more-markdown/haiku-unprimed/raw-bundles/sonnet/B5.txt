Sign up today to claim our [limited offer]{.promo} on annual plans.

Notes on the choices:

- **Item 1:** The simple table syntax lets Pandoc omit the header row.
- **Item 2:** `[text]{.promo}` renders as `<span class="promo">`.
- **Item 3:** The `{=html}` raw attribute makes the `<b>` tag appear only in HTML output.
- **Item 5:** `::: todo` is a fenced div, which renders as `<div class="todo">`, so you can style it with CSS.
- **Item 6:** `~2~` is subscript and `^10^` is superscript.
- **Item 7:** The HTML comment is dropped from the rendered output, so readers won't see it.
