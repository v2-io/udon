# Markdown features: dialects and implementations

One row per feature. The dialect columns come from the research notes and the feature matrix in `matrix/` (cell notes and sources are in its data files). The last two columns say what comrak 0.54 and pandoc 3.11 can do, and with which flag or extension, checked against the installed binaries where a test input could settle it.

Key: ● core · ◐ extension or option (named) · ◇ de facto (rendered, unspecified) · ↪ workaround, usually raw HTML · ✕ removed · – unsupported · ? not established · blank: not researched for that column.

The last two groups (features from LaTeX templates and from Obsidian plugins) were researched only through the model probes and the two implementation columns, so their dialect cells are blank.
