3. GFM

(a) Five spec extensions: tables, task list items, strikethrough, autolinks (bare URL/email), disallowed raw HTML (tagfilter). Spec base is CommonMark 0.29.

(b)

```markdown
> [!WARNING]
> Watch the broth.
```

github.com alert types: `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`.

(c) github.com rendering only. The GFM spec includes neither footnotes nor math.

(c)

(d) Pandoc’s extended CommonMark: the CommonMark reader/writer with a preset bundle of Pandoc extensions turned on. Format name for `-f` / `-t`.

6. MDX

(a) Latest major I know: **3**, roughly late 2023 or early 2024. Exact month: **unsure**. Unsure if a later major exists by 2026. The syntax break is MDX 2 (Feb 2022).

(b) CommonMark that breaks or changes in MDX 2+:
- `{...}` is a JavaScript expression.
- `<...>` is JSX and must be valid JSX (`<br />`, balanced tags). Prose like `a < b` or `<3` fails.
- Indented code blocks: unsupported; use fences. (Slightly less sure than the two above.)
- `<!-- comment -->` is not a comment.

Autolinks `<https://...>`: **unsure** whether they still parse as links.

(c)

```mdx
{/* comment */}
```

(d) Core MDX leaves YAML frontmatter alone. Add `remark-frontmatter` and `remark-mdx-frontmatter`; the latter exports `frontmatter`.
