**1.** `<p>H<sub>2</sub>O and <del>gone</del></p>`
*Assumed Pandoc (`~` subscript, `~~` strikethrough).* GFM would turn the single-tilde `~2~` into strikethrough.

**2.** `<p>See <a href="Setup">install guide</a>.</p>`
*Assumed Obsidian/wikilink syntax.* MediaWiki would give `/wiki/Setup`.

**3.** `<p>Note {% this is important %} here.</p>`
*Assumed a template tag left as literal text.* Jekyll/Liquid would try to process it as a tag.

**4.** `<p>This is <em>x</em> and <em>y</em>.</p>`
*Assumed CommonMark/GFM.*

**5.** `<div>\n**x**\n</div>`
*Assumed CommonMark, where `<div>` starts a raw HTML block, so `**x**` stays literal.* Pandoc would bold it if there were a blank line after `<div>`.

**6.** `<p>x<sup>2</sup> and a note<sup>[1]</sup></p>`
*Assumed Pandoc (`^sup^` and inline footnote `^[...]`).* The footnote would be a link to a footnote section at the bottom. Plain CommonMark leaves the carets literal.

**7.** `<p><mark>marked</mark> and <ins>added</ins></p>`
*Assumed Obsidian/Pandoc `==` highlight plus CriticMarkup `{+ +}`.* Plain CommonMark leaves both literal.

**8.** `<p>Groceries:</p>\n<ul>\n<li>milk</li>\n<li>eggs</li>\n</ul>`
*Assumed CommonMark, where a bullet list can interrupt a paragraph.* Original Markdown.pl would not make a list here.

**9.** `<p>Visit <a href="https://example.com">https://example.com</a> today.</p>`
*Assumed GFM autolinks.* Plain CommonMark leaves it as text.

**10.** `<dl>\n<dt>term</dt>\n<dd>its definition</dd>\n</dl>`
*Assumed Pandoc/PHP Markdown Extra definition lists.* Plain CommonMark gives a paragraph `term\n: its definition`.
