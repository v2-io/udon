## 3. GFM

**(a)** Tables, strikethrough (`~~x~~`), task list items (`- [x]`), extended autolinks, and the disallowed raw HTML filter.

**(b)**
```markdown
> [!NOTE]
> Text.
```
Types: `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`.

**(c)** Neither. They are github.com rendering features, not part of the GFM spec.

## 4. CommonMark

**(b)** Seven.

## 5. Pandoc Markdown

**(a)**
```markdown
[@smith2004, p. 33]
@smith2004 argues that...
[-@smith2004]
Text^[Inline footnote.]

::: {#myid .myclass}
Div content.
:::

[text]{.smallcaps key=val}

| Line one
| Line two

(@) First example.
(@) Second example.

\textcolor{red}{raw LaTeX}

% Title
% Author
% Date
```

**(b)** Pipe, simple, multiline, grid.
**(c)** `pandoc -f markdown-ext` disables an extension; `-f markdown+ext` enables it. For example, `-f markdown-smart`.
**(d)** CommonMark plus selected pandoc extensions. The exact extension set: unsure.

## 6. MDX

**(a)** MDX 3, around 2024, as far as I know. Unsure about newer releases.
**(b)**
- Raw HTML must be valid JSX: `<br />` not `<br>`, `className` not `class`, all tags closed.
- `<!-- -->` comments are invalid.
- `{` and `}` start JS expressions and must be escaped.
- `<url>` autolinks conflict with JSX tag parsing.
- Bare `<` followed by a letter is parsed as a tag.

**(c)**
```mdx
{/* comment */}
```
**(d)** Not built in. It needs a plugin such as `remark-frontmatter`, or the host framework must handle it.
