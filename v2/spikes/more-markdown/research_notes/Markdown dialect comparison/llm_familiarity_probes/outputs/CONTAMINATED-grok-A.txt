1. Djot

(a)
```djot
# Heading {#explicit-id}

_emphasis_ and *strong* and {=highlight=} and {+inserted+} and {-deleted+}
and mc^2^ and H~2~O and [Ctrl]{.kbd} and $x^2$ and a note[^n].

line one\
line two

udon
: a noodle

::: {.warning}
Watch the step.
:::

| a | b |
|---|---|
| 1 | 2 |
: Caption

``` =html
<div>raw</div>
```

[^n]: The note.
```
Caption: **unsure** (that trailing `: Caption` may be Pandoc, not Djot).

(b)
```djot
*bold* and _italic_ and {-gone-} and <https://x.com>
```

(c) Reference: **djot.js** (JavaScript) in `jgm/djot`. Same repo has an official **Lua** implementation that Pandoc uses. **jotdown** (Rust) is a separate implementation. Latest version: **unsure**.

2. Obsidian
```markdown
[[Alpha|first]]
[[Alpha#Setup]]
[[Alpha#^abc123]]

Paragraph text ^abc123

![[Alpha]]
![[diagram.png|300]]

> [!warning]- Careful
> Folded body.

==highlight==
%% hidden in reading view %%
#parent/child

---
aliases:
  - first
tags:
  - parent/child
---
```
`^abc123` at the end of the block, or alone on the next line. `|300` is width in px.

3. GFM

(a) Tables, task list items, strikethrough, autolinks (bare `www.`/`http` URLs), disallowed raw HTML.

(b)
```markdown
> [!WARNING]
> Careful.
```
Types: `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`.

(c) github.com rendering only. The GFM spec includes neither.

4. CommonMark

(a) **0.31.2**, January 2024. Latest I know; anything newer: **unsure**.

(b) **7**: script/pre/style/textarea; comments; processing instructions; declarations; CDATA; a fixed set of block tags; any other complete tag.

(c) Yes, only when the start number is **1**.

(d) No. Both underscores are intra-word, so neither opens nor closes emphasis.

(e) `<p><em>foo<strong>bar</strong>baz</em></p>`

5. Pandoc Markdown

(a)
```markdown
% Title
% Author
% 2026-10-14

[@smith2000, p. 33]
@smith2000 [p. 33]
[-@smith2000]

Inline.^[The note.]

::: {#sec .warning}
Body.
:::

[span]{#id .class}

| line one
| line two

(@) First example.
(@) Second example.

`\emph{hi}`{=latex}
```

(b) `pipe_tables`, `simple_tables`, `multiline_tables`, `grid_tables`.

(c) Glue it to the format: `-f markdown+ext` enables, `-f markdown-ext` disables.

(d) Pandoc's CommonMark with a bundle of Pandoc extensions on (footnotes, pipe tables, strikeout, tex math, attributes, and others). Separate from strict `commonmark` and from `gfm`. Exact default set: **unsure**.

6. MDX

(a) **MDX 3**, 2024. Month: **unsure**. MDX 2 was February 2022.

(b) These CommonMark forms break or change:
- `{...}` is a JavaScript expression; literal braces are `\{` `\}`.
- `<...>` starts JSX, so `a < b` and unknown tags fail.
- Indented code blocks are not code blocks.
- A line that is `import` / `export` is a statement, not a paragraph.

(c) `{/* comment */}`

(d) The compiler leaves YAML frontmatter alone. Usual path is `remark-frontmatter` plus `remark-mdx-frontmatter`, which exports `frontmatter`. Whether any later release made that default: **unsure**.

8. Confidence

- Djot: **3** — inline marks and attributes are solid; caption and current version are not.
- Obsidian: **4** — wikilinks, embeds, callouts, properties.
- GFM: **4** — spec extensions vs github.com extras.
- CommonMark: **5** — blocks, list interruption, emphasis algorithm.
- Pandoc Markdown: **4** — citations, divs, tables, `+ext`; `commonmark_x`'s exact set is fuzzy.
- MDX: **3** — JSX collisions and comments; release month and frontmatter defaults are fuzzy.
- MyST: **3** — directives and roles; options I would look up.
- Markdoc: **3** — tags and attributes only.
- AsciiDoc: **2** — headings and a few blocks; I would miss idioms.
- reStructuredText: **3** — directives, roles, simple tables.
- Org mode: **3** — headlines, drawers, links, source blocks.
- Typst: **3** — markup, `#set`/`#show`; current syntax I would check.
.com split is clear; alert list may have grown since.
- CommonMark — 4 — block and emphasis rules are familiar; spec version after 0.31.2 is not.
- Pandoc Markdown — 4 — citations, divs, tables, and `+ext`/`-ext` are familiar.
- MDX — 3 — the MDX 2 breaks are familiar; current major and frontmatter defaults are not.
- MyST — 3 — directives and roles are familiar; idiomatic option syntax is thinner.
- Markdoc — 3 — tag and attribute syntax is familiar; built-in schema idiom is thinner.
- AsciiDoc — 2 — basic blocks only; attributes and includes would need checking.
- reStructuredText — 3 — directives, roles, and headings are familiar; field and citation details slip.
- Org mode — 2 — headlines and emphasis markers only; drawers and Babel would need checking.
- Typst — 3 — markup vs script mode and basic styling are familiar; package idiom would need checking.
